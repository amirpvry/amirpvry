## Selected engineering work

### Full-stack commerce storefront — Desan
**Django / DRF · Next.js 16 · React 19 · TypeScript · PostgreSQL-ready backend**

Developed a full-stack storefront with a versioned Django REST catalogue API and a Next.js App Router frontend. Backend work includes product/category/content models, publication controls, staff-only mutations, pagination, JWT-enabled authentication, caching with optional Redis, and API schema documentation. Frontend work includes server-rendered product pages, metadata and sitemap generation, responsive product browsing, and an interactive Three.js product rack with a fallback experience.

*Private repository — described here as an engineering case study; source code is not publicly linked.*

### [AI Grading Portfolio](https://github.com/amirpvry/ai-grading-portfolio)
**Django / DRF · PostgreSQL · Redis · Celery · Docker · Pytest**

An independent backend demonstration for asynchronous Python code grading, with JWT authorization, user-scoped APIs, rubric snapshots, transactional outbox dispatch, idempotency, and lease-fenced worker recovery. Scoring is deterministic and **AST-only**: submitted code is never executed, and structural scores do not establish functional correctness.

[Architecture](https://github.com/amirpvry/ai-grading-portfolio/blob/main/docs/ARCHITECTURE.md) · [Security model](https://github.com/amirpvry/ai-grading-portfolio/blob/main/docs/SECURITY.md) · [CI](https://github.com/amirpvry/ai-grading-portfolio/actions)
