## Featured project

### [AI Grading Portfolio](https://github.com/amirpvry/ai-grading-portfolio)

An independent Django/DRF backend for asynchronous, deterministic Python code grading.

- JWT authentication, owner-scoped APIs, rubric snapshots and PostgreSQL transactions
- Transactional outbox, Redis/Celery workers, idempotency and lease-fenced recovery
- **AST-only scoring:** submitted code is never executed, and scores do not claim functional correctness
- Optional AI advisory feedback that cannot change scores
- **31 PostgreSQL-backed tests passed** in initial validation; [GitHub Actions CI](https://github.com/amirpvry/ai-grading-portfolio/actions) completed successfully

Read the [architecture](https://github.com/amirpvry/ai-grading-portfolio/blob/main/docs/ARCHITECTURE.md), [security limitations](https://github.com/amirpvry/ai-grading-portfolio/blob/main/docs/SECURITY.md), and [validation report](https://github.com/amirpvry/ai-grading-portfolio/blob/main/docs/VALIDATION.md).
